# L3RIN — Portfolio

Personal portfolio website for **Oloyede Enoch Oluwapamilerin** (L3RIN) — Backend / Python Engineer specializing in FastAPI, AI-powered APIs, and production-ready server-side systems.

**Live site:** [https://next-gen-python-developer.vercel.app](https://next-gen-python-developer.vercel.app)

---

## Overview

A minimal, modern single-page portfolio inspired by the Next.js / Vercel design language:

- Clean light theme
- Inter typography
- Subtle motion and hover states
- Sections for About, Experience, Projects, Blog, Resume, and Contact

Built to attract remote clients and showcase backend / AI work.

---

## Features

- Responsive layout (mobile + desktop)
- Sticky navigation
- Project cards and experience timeline
- Medium blog links
- Working contact form (Formspree)
- Fast static deployment on Vercel

---

## Tech Stack

- HTML5
- CSS3 (custom properties, modern layout)
- Vanilla JavaScript (scroll fade-in)
- [Formspree](https://formspree.io) for the contact form
- Deployed on [Vercel](https://vercel.com)
